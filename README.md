# cognitive-runtime

Cognitive Runtime Software

Software should not encode every possible behavior.

It should provide a bounded environment in which models can understand a situation,
choose an appropriate behavior, act through deterministic tools, verify the outcome,
and learn from experience.

This repository develops that idea through working software, experiments and architectural notes.

## Status

Experimental and under active development. The repository intentionally documents failures as well as successful results.

* [LifeAI](experiments/lifeai/README.md) — a continuous 2D world with embodied LLM agents, deterministic actions, bounded memory, dialogue, energy costs and sleep retrospection.
